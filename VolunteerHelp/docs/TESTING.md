# Тестирование

Проект содержит:

- `MatchingPolicyTest` — 8 модульных проверок категории, доступности и пересечения интервалов;
- `ApiIntegrationTest` — проверки авторизации, ролей, CSRF, создания заявок, поиска и бронирования;
- `ConcurrencyTest` — конкурентная проверка бронирования одного волонтёра.

Запуск:

```bash
mvn clean test
```

Контрольный сценарий из курсовой:
1. Войти как `customer`.
2. Создать заявку «покупки» на будущую дату, например 15:00–17:00.
3. Найти волонтёра из Центрального района.
4. Создать бронирование.
5. Повторить бронирование того же волонтёра на пересекающийся интервал — сервер должен вернуть 409.
6. Войти как `volunteer`.
7. Начать и завершить поручение.
8. Вернуться как `customer` и оставить отзыв 5/5.
