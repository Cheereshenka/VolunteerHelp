# VolunteerHelp

Курсовой проект «Разработка REST API для сервиса поиска и бронирования волонтёров». Веб-клиент и API помогают организовать бытовые поручения, например покупку продуктов, уборку и доставку.

## Запуск

Требуются JDK 17+ и Maven 3.9+. Выполните команды из корня распакованного проекта.

```bash
mvn test
mvn spring-boot:run
```

- [Веб-клиент](http://localhost:8080/)
- [Swagger UI](http://localhost:8080/swagger-ui.html)
- [OpenAPI JSON](http://localhost:8080/v3/api-docs)

## Данные

Приложение создаёт `data/volunteerhelp.json` внутри папки проекта. В одном файле хранятся пользователи с BCrypt-хэшами паролей, профили, заявки, бронирования с перепиской, отзывы и аудит. Изменения сохраняются после каждой успешной операции. Для Docker используется том `./data:/app/data`. Запускайте один экземпляр приложения на один файл.

Путь можно переопределить свойством `volunteerhelp.storage.path`. Для тестов используются отдельные файлы во временной папке. Для резервной копии достаточно скопировать файл JSON. В исходном архиве отсутствовал файл базы H2, поэтому при первом запуске приложение создаёт демоданные.

## Демо-учётные записи

| Логин | Пароль | Роль |
|---|---|---|
| customer | customer | Заказчик |
| volunteer | volunteer | Волонтёр |
| admin | admin | Администратор |

Для одновременной работы под двумя ролями откройте приложение в двух браузерах или в обычном и приватном окне. Параметр `volunteerhelp.demo.enabled=false` отключает создание демоданных.

## Как проходит поручение

1. Заказчик создаёт заявку и приглашает подходящего волонтёра. Волонтёр также может сам откликнуться на открытую заявку.
2. Получатель принимает или отклоняет предложение в разделе «Бронирования». При принятии сервер повторно проверяет доступность волонтёра. При отказе или отмене предложения заявка снова открывается.
3. Участники обсуждают детали в переписке. Точный адрес появляется у волонтёра после подтверждения бронирования.
4. Волонтёр начинает работу и отправляет отчёт. Заказчик подтверждает выполнение или возвращает отчёт с замечаниями.
5. После подтверждения заказчик может один раз оценить волонтёра. Сервер пересчитывает рейтинг.
